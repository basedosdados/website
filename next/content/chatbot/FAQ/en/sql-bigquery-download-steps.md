The chatbot always returns an SQL query along with the answer. To extract the full table in Google BigQuery:

1. Go to [Google BigQuery](https://cloud.google.com/bigquery) and open the Console.
2. Sign in with a Google account and create a project, if you don't have one yet.
3. Open a new SQL query, paste the chatbot's query and run it.
4. Save the results in your preferred format or open them in other Google tools.

If you run into trouble with this flow, our team and community can help on the [Data Basis Discord](https://discord.gg/jFUZZpA4ME).

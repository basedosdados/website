# Atribuição dos dados geográficos

Os arquivos TopoJSON deste diretório (`brazil_states.topojson`, `brazil_municipalities.topojson`) são
derivados do repositório **dados-referenciais-abertos** (https://github.com/fititnt/dados-referenciais-abertos).

- **Licença:** ODC Open Database License (ODbL) / Database Contents License (DbCL) — veja o
  `LICENSE` do repositório de origem. A própria fonte observa que a licença original dos
  dados é incerta, possivelmente de domínio público.
- **Modificações:** para os municípios, usamos a malha já simplificada e convertemos o
  código IBGE para texto; o arquivo de estados não teve alterações de conteúdo. Como base
  de dados derivada, estes arquivos permanecem disponíveis sob a ODbL.

# Geographic data attribution

The TopoJSON files in this directory (`brazil_states.topojson`, `brazil_municipalities.topojson`) are
derived from the repository **dados-referenciais-abertos** (https://github.com/fititnt/dados-referenciais-abertos).

- **License:** ODC Open Database License (ODbL) / Database Contents License (DbCL) — see the
  source repository's `LICENSE`. The source itself notes that the underlying data's original
  license is uncertain and possibly public domain.
- **Modifications:** for municipalities, the already-simplified mesh is used and the IBGE
  code is converted to text; the states file has no content changes. As a derivative database,
  these files remain available under the ODbL.
